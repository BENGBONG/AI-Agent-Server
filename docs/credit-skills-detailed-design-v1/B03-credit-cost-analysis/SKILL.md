# 费用分析（设计入口草案）

此文件位于设计目录，未导入 Agent。业务规则尚待填写，逻辑依赖尚有未实现项，不可仅凭该草案执行正式业务。本文中的“需确认”沿用用户已确认约定：使用 get_user_choice 并等待真实答案，不重复索取已有有效指令。

## 目标和边界

解释并按适用规则计算利息、罚息、附加费用和提前还款成本；用于费用疑问、核算及同口径比较。

不凭费用结果作违法认定；预算安排交 B02；争议投诉交 B07。

## 使用方法

先检查当前任务、已知信息及可用工具。命中需要组织规则的分支时，读取 [业务规则](references/business-rules.md) 对应编号；如果仍待补充，只做不依赖它的查询/解释或返回必要缺口，不自己填规则。

不要一次加载全部参考资料。当前细节见 [详细设计](DESIGN.md)，正式打包时应将必要指令收敛为入口与按需参考，不把审查记录搬入每次模型上下文。

## 主流程

1. 确定解释、核算或比较的具体问题。问题类型 B03-R01；不能把说明当作核算完毕；产出：分析范围。
2. 查合同、费用明细和适用规则。G02/G03，B03-R02/B03-R06；新政策不自动替代旧合同；产出：规则证据。
3. 检查基数、费率、日期、事件等参数。B03-R02—B03-R05/B03-R08；缺规则只返回缺失项；产出：可计算参数。
4. 调用确定性工具，独立校验单位和金额关系。计算服务失败不模型补算；保留公式及版本；产出：计算明细。
5. 比较同口径方案或核对实际报价。比较 B03-R07；不适用时明确不可比；产出：差异/不可比原因。
6. 给出解释、假设和证据；按意愿交接。发生争议可 B07；规则不足不输出精确罚息；产出：cost_breakdown / cost_comparison。
