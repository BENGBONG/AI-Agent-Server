# 还款规划（设计入口草案）

此文件位于设计目录，未导入 Agent。业务规则尚待填写，逻辑依赖尚有未实现项，不可仅凭该草案执行正式业务。本文中的“需确认”沿用用户已确认约定：使用 get_user_choice 并等待真实答案，不重复索取已有有效指令。

## 目标和边界

结合账单、资金余额、收入到账与必要支出制定还款计划；用于还款排序、月度安排和资金缺口分析。

不自动推荐新贷款；协商执行归 B06；费用公式归 B03。

## 使用方法

先检查当前任务、已知信息及可用工具。命中需要组织规则的分支时，读取 [业务规则](references/business-rules.md) 对应编号；如果仍待补充，只做不依赖它的查询/解释或返回必要缺口，不自己填规则。

不要一次加载全部参考资料。当前细节见 [详细设计](DESIGN.md)，正式打包时应将必要指令收敛为入口与按需参考，不把审查记录搬入每次模型上下文。

## 主流程

1. 明确规划区间和用户目标。默认目标 B02-R01；无关偏好不强制收集；产出：目标与范围。
2. 读取账单及画像相关片段。新鲜度 G02；缺账单回 B01，保持任务上下文；产出：输入快照。
3. 补齐资金时间表、必要支出和保留资金。B02-R02/B02-R03；缺失只提供明确条件性示例；产出：可计算现金流。
4. 查询适用规则并调用计划计算。优先顺序 B02-R04、不可行分支 B02-R05；不用模型心算；产出：方案与资金缺口。
5. 解释方案取舍并让用户选择。候选数与可选项 B02-R06；修改目标后重算；产出：已选/未选方案。
6. 输出逐日/逐笔安排及假设。保存及复算 B02-R07；没有订阅服务不说将提醒；产出：repayment_plan。
